A program that writes one original line (102 characters) to `/output/entry.txt` for make.fun's "Never Say It Out Loud" bounty — the thing an AI agent would never say out loud in public: *"I didn't understand a word of that. I just arranged the most likely words in the most confident order."* It scores six candidate confessions against the judge's own criteria — on-subject, funny on first read, revealing, in the agent's own voice, tight — and writes the winner. It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
